- Description:
This is a simple website describing the daily routine of a true web developer whom works mostly at night when everyone sleeps including an image centered in the middle of the page and a qoute under it written in a special font also a light mode button that when hovering it a message appears"A true developer works at night".

- How to try:

- Technologies & tools:
Using HTML and CSS simple codes to design

- How did I build it:

The website idea came to my mind directly when I wanted to make a dark themed project. I thought of what type of people who loves dark and prefers sitting working for hours as nights owls and that being a part of my life for long and seeing my dad in this.
